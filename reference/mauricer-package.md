# mauricer: Install BEAST2 packages.

'BEAST2' (\<http://www.beast2.org\>) is a widely used Bayesian
phylogenetic tool, that uses DNA/RNA/protein data and many model priors
to create a posterior of jointly estimated phylogenies and parameters.

## Details

'BEAST2' is commonly accompanied by 'BEAUti 2'
(\<http://www.beast2.org\>), which, among others, allows one to install
'BEAST2' package. This package allows to install 'BEAST2' packages from
'R'.

\*
[get_beast2_pkg_names](https://docs.ropensci.org/mauricer/reference/get_beast2_pkg_names.md):
get the names of all BEAST2 packages \*
[install_beast2_pkg](https://docs.ropensci.org/mauricer/reference/install_beast2_pkg.md):
install a BEAST2 package \*
[is_beast2_pkg_installed](https://docs.ropensci.org/mauricer/reference/is_beast2_pkg_installed.md):
determine if a BEAST2 package is installed \*
[uninstall_beast2_pkg](https://docs.ropensci.org/mauricer/reference/uninstall_beast2_pkg.md):
uninstall a BEAST2 package
